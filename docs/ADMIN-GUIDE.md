# Admin quick-start

Open `your-site.com/admin` and sign in with the admin email and password.

## Add a menu item

1. Go to **Items**, then **New item**.
2. Choose a **Category**.
3. Fill in the **Name** and **Description** in English and Amharic.
4. Enter the **Price (ETB)**.
5. Tick **Available** (and **Featured** to show it in the Popular section).
6. Tick any tags that apply (fasting, vegetarian, hot or cold).
7. Add a photo. It is resized and converted automatically.
8. Save. The item is live on `/menu` immediately.

## Edit, hide or delete an item

- **Edit:** Items, then the edit button on the item.
- **Sold out for today:** switch the item to unavailable. It stays on the menu, dimmed, marked "Unavailable".
- **Delete:** use delete and confirm in the dialog. This cannot be undone.

## Categories and tags

- **Categories:** create, rename, reorder or hide. You are warned if items still use a category.
- **Tags:** manage the fasting, vegetarian and hot/cold labels.

## Print the QR code

1. Go to **QR**.
2. Check that the address is your real menu address (`https://your-site.com/menu`).
3. Download **PNG** for general printing or **SVG** for large or sharp prints.

The QR code only contains the menu address, so it stays valid when you change items or prices. Print it once.

## Messages

**Messages** shows what customers sent through the contact form.

## Change your password

Go to **Settings**, enter your current password and a new one. Use a long password nobody else knows.

## Something wrong?

- Cannot sign in: check email and password; wait a few minutes if you tried many times.
- Change not showing: refresh the customer page.
- Anything else: contact the developer.
